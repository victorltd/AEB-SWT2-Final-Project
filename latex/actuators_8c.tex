{\footnotesize\ttfamily void \texorpdfstring{$\ast$}{*} actuators\+Response\+Loop (\begin{DoxyParamCaption}\item[{void \texorpdfstring{$\ast$}{*}}]{arg }\end{DoxyParamCaption})}



Main loop for processing actuator messages. 

This function runs in a separate thread and continuously reads messages from the actuators message queue. It processes each message to update the internal state of the actuators and logs the event. If the message queue is empty for a specified number of iterations ({\ttfamily LOOP\+\_\+\+EMPTY\+\_\+\+ITERATIONS\+\_\+\+MAX}), the loop exits, signaling that no more messages are expected.


\begin{DoxyParams}{Parameters}
{\em arg} & Unused parameter (can be NULL). \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
NULL
\end{DoxyReturn}

\begin{DoxyItemize}
\item Reads messages from the {\ttfamily actuators\+\_\+mq} message queue using {\ttfamily read\+\_\+mq}.
\item If a message is successfully read, it resets the {\ttfamily empty\+\_\+mq\+\_\+counter} and processes the message using {\ttfamily actuators\+Translate\+Can\+Msg}.
\item If the queue is empty, increments the {\ttfamily empty\+\_\+mq\+\_\+counter}.
\item Logs each processed message using {\ttfamily log\+\_\+event}, including the current state of the actuators.
\item Waits for 200 milliseconds between iterations using {\ttfamily usleep}.
\item Exits the loop and prints a message when the {\ttfamily empty\+\_\+mq\+\_\+counter} reaches {\ttfamily LOOP\+\_\+\+EMPTY\+\_\+\+ITERATIONS\+\_\+\+MAX}.
\end{DoxyItemize}
