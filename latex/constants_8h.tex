\doxysubsection{Detailed Description}
Defines constants and calibration values for the AEB system. 

This file contains the definitions of constants, message queue names, shared memory names, and calibration thresholds used throughout the AEB system. These constants are shared across multiple modules, ensuring consistency in the system\textquotesingle{}s behavior.


\begin{DoxyItemize}
\item Defines message queue names and sizes for inter-\/process communication.
\item Specifies shared memory and semaphore names for synchronization.
\item Includes calibration thresholds for triggering alarms and braking in the AEB system.
\item Provides speed limits for enabling the AEB system.
\item Implementates calibration values \mbox{[}Sw\+R-\/13\mbox{]} (\doxylink{software_requirements_SwR-13}{Sw\+R-\/13}) 
\end{DoxyItemize}
