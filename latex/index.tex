{\bfseries{AEB}} is an advanced active safety system that assists drivers in avoiding or mitigating collisions with other vehicles or obstacles. It detects potential frontal collisions and automatically engages the vehicle\textquotesingle{}s braking system to reduce speed or come to a complete stop, aiming to prevent or minimize impact.

To implement this system, {\bfseries{POSIX}} (Portable Operating System Interface) concepts are employed. POSIX defines programming interfaces and operating system interfaces to maintain compatibility between different operating systems, facilitating portability and interoperability of applications.\hypertarget{index_autotoc_md2}{}\doxysection{\texorpdfstring{Project Objective}{Project Objective}}\label{index_autotoc_md2}
This project is part of the final course in Automotive Propulsion Engineering, aka {\bfseries{Residência Tecnológica Stellantis 2024, SWT2}}. It is dedicated to the development of an Automotive Emergency Braking (AEB) system, aligning with Stellantis’ interests. The project takes a multidisciplinary approach, demonstrating the student\textquotesingle{}s understanding of various topics covered during the course. Key topics include Vehicle Modeling and Simulation, Agile Methodologies, Vehicular Networks, Vehicle Function Allocation, Automotive Embedded Software Modeling and Testing, and the Implementation of Automotive Control Systems.\hypertarget{index_autotoc_md3}{}\doxysection{\texorpdfstring{Main Features}{Main Features}}\label{index_autotoc_md3}

\begin{DoxyItemize}
\item {\bfseries{Collision Detection}}\+: Continuous monitoring of the vehicle\textquotesingle{}s frontal environment to identify potential imminent collisions.
\item {\bfseries{Automatic Braking Activation}}\+: In the event of a collision risk detection, the system automatically engages the brakes to reduce speed or stop the vehicle.
\item {\bfseries{Driver Notifications}}\+: Visual and audible alerts to inform the driver about potential hazards and actions taken by the system.
\end{DoxyItemize}\hypertarget{index_autotoc_md4}{}\doxysection{\texorpdfstring{Technologies Used}{Technologies Used}}\label{index_autotoc_md4}

\begin{DoxyItemize}
\item {\bfseries{Programming Language}}\+: C, leveraging POSIX-\/compatible libraries and system calls to ensure portability and efficiency.
\item {\bfseries{POSIX-\/\+Compatible Operating Systems}}\+: Development is focused on systems adhering to POSIX standards, ensuring greater code compatibility and portability.
\end{DoxyItemize}\hypertarget{index_autotoc_md5}{}\doxysection{\texorpdfstring{How It Works}{How It Works}}\label{index_autotoc_md5}

\begin{DoxyEnumerate}
\item {\bfseries{Sensors Module}}\+:
\begin{DoxyItemize}
\item Continuously monitors the environment and sends data to the AEB controller via message queues.
\end{DoxyItemize}
\item {\bfseries{AEB Controller}}\+:
\begin{DoxyItemize}
\item Processes sensor data to calculate the Time to Collision (TTC).
\item Decides whether to trigger alarms or activate the braking system based on predefined thresholds.
\end{DoxyItemize}
\item {\bfseries{Actuators Module}}\+:
\begin{DoxyItemize}
\item Receives commands from the AEB controller and performs actions such as locking seatbelts, activating alarms, or engaging brakes.
\end{DoxyItemize}
\item {\bfseries{Logging}}\+:
\begin{DoxyItemize}
\item Logs events such as alarms and braking activations for diagnostics and debugging purposes.
\item Logs are stored in the {\ttfamily log/} directory in a structured format.
\end{DoxyItemize}
\end{DoxyEnumerate}\hypertarget{index_autotoc_md6}{}\doxysection{\texorpdfstring{Project Structure}{Project Structure}}\label{index_autotoc_md6}

To build and run the project, follow the steps below\+:


\begin{DoxyEnumerate}
\item {\bfseries{Prerequisites}}\+:
\begin{DoxyItemize}
\item A POSIX-\/compliant operating system.
\item GCC 14.\+2 or newer installed on the system.
\item LCOV 2.\+3 or newer package installed on the system.
\item Doxygen Package installed.
\end{DoxyItemize}
\item {\bfseries{Building the Project}}\+:
\begin{DoxyItemize}
\item Navigate to the project\textquotesingle{}s root directory.
\item Run {\ttfamily make} to compile the source code.
\end{DoxyItemize}
\item {\bfseries{Running the System}}\+:
\begin{DoxyItemize}
\item After a successful build, execute the system with {\ttfamily make run}.
\end{DoxyItemize}
\item {\bfseries{Running Tests}}\+:
\begin{DoxyItemize}
\item To execute unit tests, use {\ttfamily make test}.
\end{DoxyItemize}
\item {\bfseries{Run tests, generating HTML file with branch and MC/\+DC coverage}}\+:
\begin{DoxyItemize}
\item To execute coverage tests and generate HTML, use {\ttfamily make full-\/cov}.
\end{DoxyItemize}
\item {\bfseries{Generating docs}}\+:
\begin{DoxyItemize}
\item To generate docs according to doxygen specification, use {\ttfamily make docs}.
\end{DoxyItemize}
\item {\bfseries{Cleaning generated files}}\+:
\begin{DoxyItemize}
\item To clean the main files, use {\ttfamily make clean}.
\item To clean the tests files, use {\ttfamily make clean} and {\ttfamily make clean-\/cov}.
\item To clean the doxygen files, use {\ttfamily make clean-\/docs}.
\end{DoxyItemize}
